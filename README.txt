ADONAI SERVICES & TP — Site vitrine (HTML / CSS / JavaScript)

CONTENU
- index.html : structure et contenu de la page
- css/style.css : styles et responsive design
- js/main.js : menu mobile, liens WhatsApp/e-mail et année automatique

LANCEMENT
Ouvrir index.html dans un navigateur. Aucun framework ni étape de compilation n'est nécessaire.

À PERSONNALISER AVANT PUBLICATION
1. Ouvrir js/main.js et remplacer whatsappNumber et emailAddress dans SITE_CONFIG.
   Le numéro WhatsApp doit être au format international, chiffres uniquement.
2. Remplacer les textes provisoires de présentation et les domaines d'intervention.
3. Remplacer les images de démonstration par les photos réelles des chantiers.
4. Vérifier le nom commercial, les coordonnées et les informations légales avant mise en ligne.

NOTE
Les photos actuellement appelées depuis Unsplash sont des images de démonstration.
Le site utilise Google Fonts pour les polices ; en l'absence de connexion, des polices système de secours sont utilisées.
